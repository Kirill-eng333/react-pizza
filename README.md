React + TypeScript Web Application (Educational Project)
Этот проект представляет собой учебную работу по созданию масштабируемого фронтенд-приложения. Основной упор в задании сделан на использование TypeScript для обеспечения строгой типизации и React для построения компонентной архитектуры.

Выполненные задачи (ТЗ):
Строгая типизация: Весь код написан на TypeScript с использованием конфигурации, требующей явного описания типов данных, что минимизирует количество ошибок при разработке.

Современная сборка: Настройка проекта выполнена с использованием Vite, что обеспечивает мгновенную горячую перезагрузку (HMR) и быструю сборку приложения.

Управление зависимостями: Проект настроен на работу с пакетным менеджером Yarn, что гарантирует стабильность версий библиотек через файл yarn.lock.

Чистота кода: Использован .gitignore для исключения системных файлов и папок зависимостей (node_modules) из репозитория, следуя лучшим практикам разработки.

Декларативный UI: Приложение разработано с использованием функциональных компонентов React, что было основным требованием учителя для освоения современных подходов.

Технологический стек:
React 18: Библиотека для создания пользовательских интерфейсов.

TypeScript: Надстройка над JavaScript для работы с типами.

Vite: Инструмент сборки нового поколения.

ESLint: Инструмент для проверки качества кода и соблюдения стандартов написания.
