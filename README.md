React Pizza Store — Advanced Frontend Educational Project
Это комплексное веб-приложение для заказа пиццы, разработанное в рамках продвинутого курса по фронтенд-разработке. Проект имитирует реальный сервис электронной коммерции и ориентирован на построение масштабируемой архитектуры с использованием профессионального стека технологий: React 18, TypeScript и Redux Toolkit.

🎯 Цель учебного задания
Продемонстрировать навыки создания надежного и производительного Single Page Application (SPA), соблюдая строгую типизацию данных и современные стандарты компонентного подхода. Основной упор сделан на работу с глобальным состоянием, оптимизацию сборки и создание бесшовного пользовательского интерфейса.

🛠 Технологический стек
Core: React 18 (Functional Components, Hooks).

Language: TypeScript (интерфейсы, типы, строгая типизация данных).

State Management: Redux Toolkit (управление корзиной, фильтрацией и каталогом).

Routing: React Router DOM v6 (динамические пути, параметры).

Styling: SCSS (модульная структура стилей для изоляции компонентов).

Infrastructure: Vite (сборка), Axios (запросы к API), React Paginate (пагинация), Lodash.Debounce (оптимизация поиска).

🚀 Реализованный функционал (ТЗ)
Динамическая навигация: Полная интеграция react-router-dom для переходов между главной страницей, корзиной и карточкой товара без перезагрузки страницы.

Система корзины: Реализована сложная логика добавления/удаления товаров, автоматический подсчет общей суммы и количества, а также селекторы для эффективного получения данных из хранилища.

Глобальный поиск и фильтрация: Реализована фильтрация товаров по категориям и сортировка (по цене, популярности, алфавиту). Поиск оптимизирован с помощью Debounce для снижения нагрузки на систему.

Оптимизация и Code Splitting: Применение React.lazy и Loadable для разделения кода на чанки, что обеспечивает быструю загрузку основного приложения.

Адаптивная верстка: Проект полностью адаптирован под различные разрешения экранов с использованием современной CSS-архитектуры.

🏗 Архитектура проекта
Проект придерживается принципа разделения ответственности (Separation of Concerns):

Компоненты: Переиспользуемые блоки интерфейса.

Страницы (Pages): Основные виды приложения (Home, Cart, FullPizza, NotFound).

Redux Slices: Изолированная логика управления состоянием для разных частей приложения.

Layouts: Общие шаблоны страниц для соблюдения единообразия дизайна.
